## 已确认的产品选择

用户通过 `grill-with-docs` 明确选择：项目页按会话分组列回合，点击直接进入独立回合页；目录与阅读页移走大状态卡和搜索表单，只保留必要导航及简短状态；每页完整保留该回合用户／AI 消息和折叠的工具最后结果，提供上一回合、返回目录、下一回合。规格见 [turn-pages/spec.md](../../.scratch/turn-pages/spec.md)。

因此正常路径为“项目 → 按会话分组的回合目录 → 单回合阅读”。被移走的是页面中的信息块，没有删除项目、会话或原始记录。数据库路径与详细采集状态移到 `/status`，搜索移到 `/search`，受管理删除可从顶部删除管理进入。

## 数据读取与身份

- `turn_snapshots` 保存每个版本的阅读元数据，`turn_entries` 保存回合身份、展示顺序和载荷引用，`turn_payloads` 按内容 SHA-256 去重并压缩正文，`turn_items` 为旧命中链接保留轻量定位。
- 回合稳定身份为来源实例、会话 ID、来源 turnId；“回合 1”仅为会话内展示编号。
- 项目页只读取索引元数据；单回合及其历史版本只取所选回合载荷。不再因阅读该回合而解压整会话快照、构建全会话附件／执行历史或扫描其他会话关系。
- 懒加载同时携带 turnId、来源和保存版本，避免不同回合的同名条目串用。附件校验与读取限定在该回合，证据引用继续指向原始保存包，不裁剪后重用原证据数组索引。
- 搜索使用最新回合投影并保留命中来源、保存版本和条目位置；旧完整会话 API 与导出保持原语义。
- 新保存与投影同事务；删除清理快照对应的回合／命中引用，随后回收无引用的共享载荷。投影可从原始快照重建。

## 回归、审查和浏览器

先加入能失败的公开回归，再实施：旧项目页没有回合独立链接，测试失败；新目录、当前回合、旧保存版本及按回合懒加载都可在 SQLite 拒绝读取 `snapshots.package` 的条件下工作。

最终 `python -X utf8 -m unittest discover -v`：44 项通过，28.455 秒。`python -m mypy prompt_journal`：15 个源码文件通过。`git diff --check` 通过。

Standards 轴与 Spec 轴初审发现并修复了旧附件引用、旧链接版本定位和删除入口兼容问题。旧快照缺少附件投影时，从原证据以 `acquire=False` 推导缺失引用，不读取今天的文件冒充历史内容；投影版本 2 会重建早期投影。旧搜索链接通过轻量条目索引转到原保存版本；旧 `#turn-N` 超出第一页时，先取对应元数据页再跳转。删除管理页提供已归档会话入口，原会话目录兼容路径仍可管理。两个轴最终均无未解决的可行动问题。

使用 Playwright CLI 独立浏览器验证一个会话含 65 个回合的受控样本：

- 目录每页 30 个回合，空闲两次轮询无正文预取；目录／阅读均无侧栏、状态大卡或搜索表单。
- 第二页打开回合 → 下一回合 → 上一回合 → 返回原分页位置；每个阅读页 DOM 只有一个回合。
- 长工具结果按所选 turnId 和保存版本加载，完整文本与预设值一致，原始证据载荷匹配。
- 独立搜索直接命中回合 34，保存版本与高亮保留；旧搜索 URL 可转到同一版本。
- 旧 `#turn-40` 能打开第 41 个回合，覆盖超过第一页的旧锚点。
- 独立状态和删除管理入口可用。
- 桌面与 390 px 窄屏无横向溢出，目录及阅读的截图已批量检查。Impeccable 检测器结果为空数组。

随后在正式 `8766` 对用户标注的 7 回合会话再走通：目录 → 回合 1 → 下一回合 → 上一回合 → 原始证据 → 返回目录；用户原来的 `#turn-3` 地址正确跳至回合 4；独立搜索可限定该会话、固定保存版本并高亮，返回搜索结果正常。正式浏览器检查所有判据为 true。

## 正式库完整性与空间

在停止旧 8766 后建立 SQLite 一致性备份，先于副本验证迁移，再迁移正式库。冻结数据集为 1,430 个快照、4,475 条回合版本记录；内容去重后为 1,212 份回合正文，压缩载荷共 157,182,394 字节。

逐快照比较迁移前备份与正式库的原始存储字节 SHA-256，全部一致；采集状态原始内容也一致。`quick_check` 通过，投影均为版本 2。迁移仅新增可重建投影，没有改写原始快照及证据。

冻结库迁移前为 2,174,734,336 字节，完成投影并回收初期重建产生的空闲页后为 2,364,801,024 字节；净增加约 190 MB（8.7%），用于独立读取当前和历史回合，未复制整段会话的原始证据。恢复采集后库体积会继续随新记录增长。

原始完整性记录在源码外 `D:\AI\日志验证\turn-pages-20261027\integrity.json`。压缩快照的迁移前数据库备份为同目录 `before-turn-pages.sqlite3`，约 2.17 GB，单独占用恢复空间；上一轮的压缩前恢复归档也保持原样。
