## 已实施

- `/usage` 与只读 `/api/usage`；全局导航增加「用量概览」。复用编目台与已确认预览，保留全宽热力图、活跃时间、交互模型环图及明细表，无统计保存期限选择。
- `usage.py` 只读来源明确提供的 Codex home 下 `sessions`／`archived_sessions` 的 JSONL；通过历史接口会话身份归属项目。已关闭子 agent 仅在运行记录具有明确、可核对父会话时关联；不能归属的文件单独报告。
- SQLite 独立统计事实、身份目录、缺口、检查点及运行状态。检查点只保存会话／回合／模型身份、累计基线、文件边界哈希和续读位置，不保存原始行、消息、指令、工具载荷。
- 完成回合按来源身份去重；累计 token 必须能证明增量，继承基线、重复累计、未知基线和重置不会直接累加。缓存输入属于输入细分，不再次加入总量。次数按回合开始时间，token 按用量事件时间分布，采用上海自然日／小时。
- `Collector` 启动独立统计线程。首次回补及后续增量与正文采集分开；来源中断可自动重试，统计失败不阻断对话保存，容量达到上限时暂停新增统计。浏览器不负责采集，正常视图约每 10 秒读取一次聚合结果。
- 事实固定保留滚动 90×24 小时；每日视图为上海自然日范围。清理仅处理统计事实、缺口及不再续读的检查点，不清理快照或附件，不重设正文启用时间。
