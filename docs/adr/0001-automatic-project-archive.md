# 自动归档并按项目、会话保留边界

2026-10-25，用户确认日常使用只保留自动同步，取消逐项目／会话选择后手动同步的前置流程，因为多项目、多会话并行时容易忘记操作而遗漏记录；采集器应自动发现本机支持来源中的项目、新会话和更新，并在恢复运行后补回来源仍保留的记录。

不同项目分别归档，同一项目的会话按来源会话开始时间从早到晚排列，每个会话完整展示；用户明确选择了这一方案，放弃跨会话按消息时间交错展示，较早会话产生新消息也不改变会话排序，缺少开始时间时标为未知而不以采集时间冒充。

该决策替代正式规格中“先选择采集范围、再手动同步”的旧约束，任务 03、04 合并交付；自动归档仍受本机只读来源、数据不外发及删除排除规则约束，不扩展为扫描整台电脑任意应用的历史。首次历史回补范围按任务 03 确认为只采集启用后开始的新回合；Windows 登录后隐藏监视器及桌面应用生命周期联动见 [ADR 0003](0003-desktop-following-collector.md)。
