# Triage labels

| 技能角色 | 本地标签 | 含义 |
| --- | --- | --- |
| needs-triage | needs-triage | 待评估 |
| needs-info | needs-info | 需要补充信息 |
| ready-for-agent | ready-for-agent | 定义清楚，可交给 agent 执行 |
| ready-for-human | ready-for-human | 需要人工实施 |
| wontfix | wontfix | 不予实施 |

技能提及角色时使用对应本地标签。项目任务以 `Status:` 行保存状态。
