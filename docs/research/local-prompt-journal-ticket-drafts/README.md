每张任务跨越其功能所需的采集/存储/查询/界面/验收路径；已有仓库尚无实现代码，无需先做重构。首张仅支持一个会话及最小界面，后续逐步扩展。所有任务继承本机处理、只读历史、无上下文注入和无额外模型调用的约束；验收以应用公开行为为主，真实来源通过薄契约检查校准。

## 已确认的拆分

1. **读取一段真实会话并在本机查看、导出**。Blocked by：无。交付：用户选择一段无敏感内容的真实 Codex 桌面会话后，能在本机看到已保存的提示原文和 AI 消息，并导出可核对的结构化记录。用这条最小路径确认实际数据源可用。 [正式任务](../../../.scratch/local-prompt-journal/issues/01-single-session-proof.md)
2. **查看工具参数、结果与执行状态**。Blocked by：01。交付：用户在已导入会话中展开一次工具执行，能看到对应参数、结果、可取得的状态与原始证据；并行工具、失败和缺失记录不会混淆。 [正式任务](../../../.scratch/local-prompt-journal/issues/02-tool-evidence.md)
3. **选择项目与会话的采集范围**。Blocked by：01。交付：用户可以查看可访问的项目/会话列表，选择要归档的项目或会话，并手动同步所选范围；未选择的会话不会被批量归档。 [正式任务](../../../.scratch/local-prompt-journal/issues/03-capture-scope.md)
4. **持续同步并在中断后补回记录**。Blocked by：02、03。交付：用户选定采集范围后，新回合和工具状态自动更新；采集器退出再启动、重复通知或遗漏通知后，能够从来源中仍存在的历史恢复一致记录。 [正式任务](../../../.scratch/local-prompt-journal/issues/04-incremental-recovery.md)
5. **关联后台任务、子 agent 与分叉会话**。Blocked by：02、03。交付：用户从选定主会话中追踪后台任务和子 agent，能分清启动、轮询、退出及不同分支，不把启动成功当作任务完成。 [正式任务](../../../.scratch/local-prompt-journal/issues/05-execution-topology.md)
6. **用中文搜索提示、回答和工具结果**。Blocked by：02、03。交付：用户可以在指定项目或会话中搜索中文内容，并从命中结果定位对应回合和原始证据。 [正式任务](../../../.scratch/local-prompt-journal/issues/06-chinese-search.md)
7. **标注结果并关联后续纠正**。Blocked by：01。交付：用户对一次回答标记满意度和原因，并把后来补充的要求关联到原提示或输出，保存可反复查看的复盘证据。 [正式任务](../../../.scratch/local-prompt-journal/issues/07-feedback-corrections.md)
8. **保存提示版本并比较使用案例**。Blocked by：07。交付：用户从历史提示建立一个改写版本，查看修改内容和原因，将版本关联实际案例及结果标签，以便积累改进依据。 [正式任务](../../../.scratch/local-prompt-journal/issues/08-prompt-versions.md)
9. **归档附件并导出可离线核对的会话包**。Blocked by：05。交付：用户导出选定会话及选定关联会话时，取得结构化记录、原始证据、已取得附件和缺失清单，在断网条件下仍可核对。 [正式任务](../../../.scratch/local-prompt-journal/issues/09-offline-evidence-export.md)
10. **删除受管理日志并阻止自动重新导入**。Blocked by：04、08、09。交付：用户删除一个已归档会话时，日志系统清理其受管理记录、附件引用及复盘数据，后续自动同步不会使它未经选择重新出现。 [正式任务](../../../.scratch/local-prompt-journal/issues/10-managed-deletion.md)
11. **验证首版完整复盘流程与本机运行边界**。Blocked by：04、06、10。交付：用户能够在 Windows 本机完成一次从范围选择、持续归档、检索、标注、提示比较到导出/删除的完整流程，并看到当前版本的兼容性、完整性和开销证据。 [正式任务](../../../.scratch/local-prompt-journal/issues/11-release-verification.md)

## 依赖核对

- 01 为首个可执行任务；真实数据入口验证未通过时，后续依赖不得解锁。
- 02 和 03 可在 01 后分别推进；07 也只依赖 01，人工复盘可较早验证。
- 04 需要工具状态语义和采集范围；05、06 同样依赖工具内容及会话范围。
- 08 依赖已有反馈/纠正交互。09 依赖关联会话和工具关系，才能核对完整离线会话包。
- 10 需自动同步、提示案例及附件都已存在，才能验证删除不会重新出现且关联清理正确；它不人为等待搜索界面。
- 11 汇合持续同步、中文搜索和删除；其余能力通过传递依赖已经就绪。11 不替代各任务自己的测试。
