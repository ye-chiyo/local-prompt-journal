# 只保留对话，删除工具板块与存储

2026-10-27 用户明确要求删除“工具调用与最终结果”，包含大量不支持条目和看不懂的执行过程，实际减小数据库容量。

验收状态：2026-10-27 用户确认通过并要求最终收尾；实现、正式库清理及体验验证均已完成，统一本地提交，不自动 push。

- 针对当前本机数据库的全部已保存版本，删除 tools、unsupportedItems 和对应原始协议载荷；回合目录和用户／AI 消息保留。
- 保留消息的身份、顺序、阶段、时间、完整文本、原始消息对象及消息附件；不改动评价、纠正关系、删除排除和采集启用时间。
- 来源证据变为明确标注的消息摘录，不再声称保留完整协议响应。修正消息及附件证据位置。
- 持久化只保留对话策略，后续采集在入库与附件取得之前过滤工具；工具变化不再导致保存新版本。
- 停服后建立独立一致性备份，在同一事务中改写全部版本和目录／回合投影，验证消息与附件一致，再 VACUUM 回收空间。
- 现有附件字节保留，以便恢复备份；正文中的工具名称、代码等属于用户／AI 消息，不按关键词删除。
- 验证重启、历史读取、搜索、附件、前后／返回导航和真实库体积／响应时间。

本需求更新上一轮工具原文与最终结果保留约束。见 ADR 0002。
