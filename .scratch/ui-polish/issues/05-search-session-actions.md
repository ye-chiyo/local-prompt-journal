# 05: 统一搜索与会话批量操作体验

Status: ready-for-agent
Execution: resolved
Blocked by: 03

## What to build

用户从搜索定位命中内容并勾选会话审阅后导出或删除，目录的批量操作使用一致体验。

## Acceptance criteria

- [ ] 搜索表单、命中高亮、空结果与阅读链接统一且可用。
- [ ] 同会话多命中只选择一次；勾选与阅读状态独立，刷新不清空勾选。
- [ ] 未选择时留在原页，居中仅显示请选择会话，约2秒后渐隐，重复触发重置计时。
- [ ] 导出与删除复用既有审阅流程，危险样式明确；删除仅用隔离数据验收。

## Context
