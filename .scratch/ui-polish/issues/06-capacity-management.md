## What to build

左下角数据库容量进入设置，使用量和暂停状态一致；采集状态与删除管理沿用同一视觉系统。

## Acceptance criteria

- [x] 容量不超过80%蓝色，超过80%且未满黄色，达到或超过上限红色并说明暂停新会话。
- [x] 无上限、单位和统计口径清楚，设置与恢复行为复用既有逻辑。
- [x] 状态、管理、容量页使用一致控件、排版、空状态与焦点。
- [x] 删除排除说明限定于符合原有采集条件的会话，不暗示回补全部历史。
- [x] 用隔离数据复用容量和管理验收，不修改真实库设置制造边界。
