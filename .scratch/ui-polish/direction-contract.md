# 当前方向约定：A 分区工作台，右侧按需阅读

Revision: 2026-10-27

当前规格见 [spec.md](spec.md)，视觉令牌与尺寸见 [DESIGN.md](../../DESIGN.md)。本约定替代 B 方案与 A 的早期「右侧仅显示会话资料」布局。

用户明确选择 A，随后要求贴近更鲜明的桌面参考图，并确认「右侧按需显示正文，并提供打开独立页面入口」。PC 主路径使用深蓝导航、会话列表、紧凑回合目录与右侧阅读区。会话基本信息放在上方，来源默认收起。

主要参考：[已确认桌面参考图](reference/approved-desktop.png)。图中示例名称、业务标签、日期筛选和新建项目等不自动成为功能范围。保留产品名称「本机会话记录」。

目录只查基本信息；点击回合才加载该回合。项目／会话／回合身份、排序、原文、消息来源摘录、附件、保存版本和返回分页参数保持。工具记录不恢复。

验收入口已获用户确认：真实浏览器主路径与同尺寸截图对照；导出、删除和容量复用既有集成验收，删除只用隔离测试数据，不堆叠无感知测试。

方向已确认，无需重复询问；完整视觉对照尚未完成，不能标为已验收。
