## 来源调查

2026-11-08 本机实查：`thread/turns/list` 的 `notLoaded` 视图有 `startedAt`、`completedAt`、`durationMs`，本次样本没有 token 或模型字段。

本机 Codex 运行记录有 `session_meta`、`turn_context.model`、`event_msg:task_started`、`event_msg:task_complete`、`event_msg:token_count`。token 样本包括 `total_token_usage`、`last_token_usage`、输入、缓存输入、缓存写入、输出、推理输出及总量。这里只确认样本可得，其他版本、模型和历史记录的覆盖率待实现验证。

现有来源客户端只通过历史协议读取对话。本功能增加独立的本机统计元数据读取器，不改变原正文采集边界。逐行处理运行记录时只投影允许字段，不持久化原始行、提示、回答、工具载荷或指令。

## 统计口径

| 指标 | 口径 |
| --- | --- |
| 回合次数 | 来源实例、会话 ID、回合 ID 去重；以来源完成事件为完成依据，不以采集次数或消息条数计数 |
| 时间归属 | 默认 Asia/Shanghai；次数按回合开始时间归日，token 按用量事件发生时间归日；跨午夜分别处理 |
| 总 token | 保留来源报告的总量，不用字符数估算；输入与输出分列 |
| 缓存输入 | 属于输入的细分项，不重复加到总量；缓存写入、推理输出同样按来源口径披露 |
| 活跃时段 | 每小时回合数、token 的分布；不宣称用户在线、键鼠操作或实际工作时长 |
| 模型用量 | 按用量事件对应的模型统计 token、占比和回合数；同回合切换模型时，回合总数仍去重，模型回合数可重叠并说明 |
| 未知值 | 缺失模型归入“模型未知”；缺失 token 显示“未取得”，不记为零；图表显示已知覆盖率 |
| 子会话 | 保留来源类型与父会话关系，提供主会话／子 agent／全部筛选；默认主会话，子 agent 用量可单独查看 |

不得直接累加反复出现的累计 token。读取器保存来源定位、累计基线与事件身份，处理重复、断点续读、文件截断、计数重置、分叉继承与重启。只有能够证明新产生的增量才归入当前会话；无法归属或累计基线未知时保留缺口，不能猜测模型或归属。

首次只读取明确 Codex home 下受支持运行记录；通过来源会话身份归属项目，不从消息文本猜路径。不把故障、未识别版本或缺文件显示为空白的“零用量”。默认范围仍为本项目支持的本机 Local／Worktree 会话。

## 页面

新增“用量概览”入口与 `/usage` 页面，独立于正文阅读；拟提供只读 `/api/usage`。

1. 顶部范围：今天、最近 7 天、最近 30 天、最近 90 天，默认最近 90 天；项目、来源类型筛选；更新时间和来源状态。
2. 概览：完成回合数、总 token、输入／输出、活跃天数；进行中与中断另列。
3. 时间趋势：独立占满一行，默认 90 天日历热力图，每列一周、每行对应星期中的一天。默认以 token 深浅显示，可切换回合数。移除右侧固定日期数值；悬停、聚焦或点击方格在附近显示浮层，包括日期、精确总 token、输入、输出及完成回合数；保留简短“少／多”图例。
4. 活跃时间：00—23 点柱状图，提示具体小时与数量。
5. 模型分布：使用按模型独立可交互的环状扇区。悬停、聚焦或点击扇区／图例时，扇区轻微向外移动、其他扇区淡化、中心数值与图例联动，浮层显示模型名、精确总 token、输入、输出及占比。支持键盘焦点、Enter／Space 与 Esc；减少动态效果下停用位移动画。活跃时间与模型环图并排，模型明细和项目明细另起一行。
6. 项目用量：项目、回合数、token 的排行表；可进入项目范围。
7. 数据说明：最近成功更新、可统计与缺失数量；空状态、首次回补、部分失败及来源不可用都给出明确提示。

不复制截图中的装饰横幅、煤矿业务内容或示例统计。`preview.html` 是独立示例预览，全部数值为模拟数据，不读取真实对话。

## 保存与运行

- 统计使用独立表，不将 token 写回对话快照。新增表、来源检查点、清理任务与现有数据库容量策略协调。
- 固定保留最近 90×24 小时的统计事实，页面不提供保存周期选择。日期筛选只影响查看范围，不改变保存策略。
- 清理同时覆盖明细、聚合、持久化缓存；检查点只保留续读所需信息，不能使过期统计重新回补。
- 监控在现有桌面监视器管理的服务运行期间持续更新，浏览器关闭仍可采集；重启后补采仍在保存期内的记录。
- 默认增量读取，首次回补独立执行；异常隔离，统计失败不能阻断对话归档。页面定时更新只读聚合数据。
- 正式启用需有源码外一致性备份并保留回退方法，不重设原正文启用时间。
