# 随 ChatGPT 桌面应用启动 Codex 日志采集

Status: ready-for-agent

## 用户目标

用户希望打开 ChatGPT 桌面应用后，Codex 本机对话日志自动开始采集，无需手动运行服务；关闭应用后停止采集。

## 已确认决策

- 仅记录桌面应用中由本机 Codex 历史接口可读的 Codex Local／Worktree 会话；普通 ChatGPT 对话与 Cloud 会话不在范围内。
- 用户登录后运行隐藏监视器；监视器识别桌面应用主进程，而非任一 Electron 子进程。
- 监视器启动时若应用已经运行，立即启动采集器。
- 桌面应用主进程退出后停止采集器。仅关闭窗口但主进程仍存活时继续采集。
- 采集器在应用仍运行时意外退出，由监视器自动重启。
- 使用现有正式数据目录、采集策略和 `enabledAt`；不传 `--start-from-now`，不回补原启用时间之前的回合。
- 登录监视器只观察桌面应用进程；采集器继续通过 Codex App Server 只读历史接口读取会话。

## 验收标准

- 能识别 ChatGPT 桌面主进程启动、运行和退出；renderer/utility 子进程不能单独触发采集。
- 监视器启动时应用已运行会立即启动采集器；应用运行期间采集器意外退出会自动重启。
- 应用主进程退出后采集器正常停止，不遗留采集服务或监听端口。
- 用户级隐藏登录启动项可安装、重复安装幂等、可明确移除；不修改机器级配置。
- 采集服务以现有数据目录启动，沿用既有范围和 dialogue-only 策略。
- 验证覆盖自动化受控进程场景及实际 Windows 启动入口；不读取或修改 Codex 原始会话。
