## 执行规则

除合并后不独立实施的 04（wontfix）外，实施任务沿用既有 triage 标签；只有阻塞任务完成后才能开始相应任务。01、02 已完成，下一自动归档交付入口为 03，尚未实施。

01 必须通过真实数据源的关键记录读取验证；仅固定样本通过不能解锁后续任务。每张任务自行验收其完整功能链路，11 汇总跨功能和运行环境验证。

本次修订只更新需求与任务，不实现自动归档，不扩大任务 01、02 已有真实验证结论。03 交付时一次完成公开行为验证与用户验收；用户明确通过后才登记完成并提交一次相关 commit，不自动 push。

Windows 登录后自动启动及首次运行的旧历史回补范围仍待确认。所有会话自动发现不等于允许任意读取其他应用；来源访问限制、本机处理及删除排除继续适用。
