# 08 — 保存提示版本并比较使用案例

**What to build:** 用户从历史提示建立一个改写版本，查看修改内容和原因，将版本关联实际案例及结果标签，以便积累改进依据。

**Blocked by:** 07 — 标注结果并关联后续纠正

**Status:** ready-for-agent

- [ ] 保留原始提示与多个改写版本、修改说明和任务用途，编辑改写版本不覆盖原始证据。
- [ ] 对比版本差异，能够查看对应使用案例和人工反馈；未使用的版本清楚标记为待验证。
- [ ] 在来源可取得时展示案例的模型及上下文/环境元信息，缺失项标为未知；版本差异与结果相关不被表述为已证明因果。
- [ ] 版本、案例和反馈关联在重启及重复同步后保持一致，不依赖对话文本相同推断身份。
- [ ] 通过建立、比较、修改版本与关联不同结果案例验收完整工作流，全部功能在无额外模型条件下可用。
