# 09 — 归档附件并导出可离线核对的会话包

**What to build:** 用户导出选定会话及选定关联会话时，取得结构化记录、原始证据、已取得附件和缺失清单，在断网条件下仍可核对。

**Blocked by:** 05 — 关联后台任务、子 agent 与分叉会话

**Status:** ready-for-agent

- [ ] 归档来源已提供或本机可访问的图片及其他附件，保存稳定引用和校验信息；不为下载远端附件主动发送日志内容。
- [ ] 未取得、已删除或只有远端引用的附件明确列为缺失，不把解析后文本导出当作完整原生备份。
- [ ] 导出保留会话/回合/调用身份、关系、工具状态、内容完整性和证据清单，并尊重选定采集及关联会话范围。
- [ ] 已取得附件随导出包离线访问，日志软件重启或原附件移动后，受管理副本仍可核对。
- [ ] 通过无附件、共享附件、已取得附件和缺附件样本验证采集、展示引用与离线导出；导出不需要重新执行历史任务。
- [ ] 结构化导出格式携带版本信息，明确哪些部分来自原始来源、哪些属于规范化表示。
