# 03 — 选择项目与会话的采集范围

**What to build:** 用户可以查看可访问的项目/会话列表，选择要归档的项目或会话，并手动同步所选范围；未选择的会话不会被批量归档。

**Blocked by:** 01 — 读取一段真实会话并在本机查看、导出

**Status:** ready-for-agent

- [ ] 枚举当前来源可见的会话及项目归属，支持按项目筛选；未取得的元信息标为未知。
- [ ] 保存项目级或会话级选择，并明确项目级选择是否包含其后新出现的会话；界面与实际行为一致。
- [ ] 手动同步仅对选定范围归档消息正文和附件；取消选择停止后续采集，已保存内容保持可访问，删除由独立操作完成。
- [ ] 跨会话保留来源、会话、回合和条目身份，不因同名项目、会话标题或文本相同而合并记录。
- [ ] 界面显示选定范围、可访问会话及读取失败；来源不可用与实际没有会话有不同状态。
- [ ] 用两个项目、多会话和一个不可访问会话验证列表、选择、保存、同步和结果展示；日志正文不上传。
