# 10 — 删除受管理日志并阻止自动重新导入

**What to build:** 用户删除一个已归档会话时，日志系统清理其受管理记录、附件引用及复盘数据，后续自动同步不会使它未经选择重新出现。

**Blocked by:** 04 — 持续同步并在中断后补回记录；08 — 保存提示版本并比较使用案例；09 — 归档附件并导出可离线核对的会话包

**Status:** ready-for-agent

- [ ] 删除后该会话原始归档、查询索引、受管理派生结果、人工标注及提示案例引用按一致规则清理。
- [ ] 保留其他会话仍引用的共享附件和独立提示版本，移除被删会话的关联；孤立的受管理附件得到清理。
- [ ] 删除排除标记与自动同步协同，后续对账不自动重新归档被删会话；显式重新导入可解除排除。
- [ ] 清楚说明删除范围是本应用管理的数据，不改变 Codex 原会话，不声称擦除用户另存的导出副本。
- [ ] 删除过程中出现失败时显示可恢复状态；恢复操作或重启后不会把部分删除误报为完成。
- [ ] 通过公开查询/导出、重启、同步及共享引用场景验证删除效果和其他会话的完整性。
