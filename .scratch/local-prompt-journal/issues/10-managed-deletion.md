# 10 — 删除受管理日志并阻止自动重新导入

**What to build:** 用户删除一个已归档会话时，日志系统一致清理该会话的归档、来源历史修订、证据、搜索所用内容及受管理附件引用，并保留删除排除标记，使后续自动同步不会未经显式恢复重新归档。删除范围仅限本日志应用管理的数据。

**Blocked by:** 03 — 多项目自动归档与持续同步；09 — 归档附件并导出可离线核对的会话包

**Status:** ready-for-agent

- [ ] 删除后，该来源实例中的目标会话正文、工具记录、历史修订、原始证据及应用内搜索内容不再可访问；其他来源、项目与会话不受影响，不因文本或名称相同误删。
- [ ] 保留其他会话仍引用的共享附件，清理不再被引用的受管理附件；来源关联不再指向可打开的已删正文，其他会话自身的原始证据不被改写，关系是否仍由来源提供应如实说明。
- [ ] 删除排除标记与自动同步协同，后续对账不自动重新归档被删会话；用户显式恢复并解除排除后才允许自动重新归档，不要求恢复日常手动同步。
- [ ] 清楚说明删除范围是本应用管理的数据，不改变 Codex 原会话，不声称擦除用户另存的导出副本。
- [ ] 删除过程中出现失败时显示可恢复状态；恢复操作或重启后不会把部分删除误报为完成。
- [ ] 通过公开查询/导出、重启、同步及共享引用场景验证删除效果和其他会话的完整性。
