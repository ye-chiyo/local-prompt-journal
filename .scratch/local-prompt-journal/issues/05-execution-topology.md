# 05 — 关联后台任务、子 agent 与分叉会话

**What to build:** 用户从正在查看的已归档主会话追踪后台任务和子 agent，能分清启动、轮询、退出及不同分支，不把启动成功当作任务完成。

**Blocked by:** 02 — 查看工具参数、结果与执行状态；03 — 多项目自动归档与持续同步

**Status:** ready-for-agent

- [ ] 关联当前来源可取得的后台命令启动、轮询和退出证据；无退出证据时保持未知。
- [ ] 展示主会话、子 agent 和分叉关系，点击后查看对应证据，消息不混入其他会话回合。
- [ ] 主会话关联的子会话遵守任务 03 的自动归档规则、来源访问限制和删除排除；关系链接不自动授权读取其他来源或绕过排除，未归档或不可访问时明确说明。
- [ ] 未暴露的父子关系、子会话或后台结果标明不可得；异步到达顺序不冒充执行因果顺序。
- [ ] 从主会话导出时显式选择是否包含已获授权归档的关联会话，并保留关系信息。
- [ ] 通过后台成功/失败/未知退出、子 agent 和分叉样本验收显示与导出，所有浏览保持只读。

2026-10-25：随自动归档决策更新前置任务名称及归档边界，不再依赖手动选择采集范围；选择查看或导出某个会话仍是正常浏览操作。本任务未开始，其他验收范围不变。
