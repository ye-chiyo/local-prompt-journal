# 05 — 关联后台任务、子 agent 与分叉会话

**What to build:** 用户从选定主会话中追踪后台任务和子 agent，能分清启动、轮询、退出及不同分支，不把启动成功当作任务完成。

**Blocked by:** 02 — 查看工具参数、结果与执行状态；03 — 选择项目与会话的采集范围

**Status:** ready-for-agent

- [ ] 关联当前来源可取得的后台命令启动、轮询和退出证据；无退出证据时保持未知。
- [ ] 展示主会话、子 agent 和分叉关系，点击后查看对应证据，消息不混入其他会话回合。
- [ ] 选定主会话关联的子会话应展示实际归档范围；不读取范围外正文，需扩大范围时通过已有选择操作完成。
- [ ] 未暴露的父子关系、子会话或后台结果标明不可得；异步到达顺序不冒充执行因果顺序。
- [ ] 从主会话导出时显式选择是否包含已获授权归档的关联会话，并保留关系信息。
- [ ] 通过后台成功/失败/未知退出、子 agent 和分叉样本验收显示与导出，所有浏览保持只读。
