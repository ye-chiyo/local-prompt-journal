# 02 — 查看工具参数、结果与执行状态

**What to build:** 用户在已导入会话中展开一次工具执行，能看到对应参数、结果、可取得的状态与原始证据；并行工具、失败和缺失记录不会混淆。

**Blocked by:** 01 — 读取一段真实会话并在本机查看、导出

**Status:** ready-for-agent

- [ ] 将当前来源可取得的命令、MCP、动态工具及独立函数输出展示在正确回合；嵌套调用无法独立获取时显式报告边界。
- [ ] 按来源调用身份关联请求与结果；并行工具不串线，相同参数的不同调用仍为不同执行。
- [ ] 保存可取得的工具参数、返回内容、退出码/错误信息和相关时间；缺失字段使用未知状态，工具执行成功不自动等同业务成功。
- [ ] 截断、未支持事件和未取得结果有明确标记，原始载荷仍可核对；长输出按需展开，显示摘要不替代归档原文。
- [ ] 界面与结构化导出呈现同一调用关系和完整性状态。
- [ ] 通过成功工具、失败工具、并行调用、长输出与缺结果样本验收从采集到展示/导出的外部行为，保持本机数据隔离约束。
