# 11 — 验证首版完整复盘流程与本机运行边界

**What to build:** 用户能够在 Windows 本机完成一次从多项目自动归档、按会话开始时间完整浏览、检索、标注、提示比较到导出/删除的完整流程，并看到当前版本的兼容性、完整性和开销证据。

**Blocked by:** 03 — 多项目自动归档与持续同步；06 — 用中文搜索提示、回答和工具结果；10 — 删除受管理日志并阻止自动重新导入

**Status:** ready-for-agent

- [ ] 按正式规格运行完整用户流程及真实来源薄契约检查，汇总各已实现能力的通过、缺口和不支持项；不能仅凭固定样本通过宣称桌面兼容。
- [ ] 验证全部新增日志组件没有远端数据发送、额外模型调用或会话上下文注入；需要启动的本地界面只监听回环地址。
- [ ] 在实际 Windows 启动、重启和离线浏览场景复核归档、中文检索、反馈、版本比较、附件导出和删除排除行为。
- [ ] 两个项目并行、新会话自动发现及中断补回无需手动同步；同项目 A 先开始、B 后开始、A 再更新时，仍完整展示 A 后完整展示 B，保持项目隔离和原有执行过程折叠方式。
- [ ] 在相同受控条件下记录有无采集的回合耗时、采集延迟、CPU、内存与磁盘写入及样本规模；给出数值预算建议，不伪造预先确认的性能阈值。
- [ ] 向用户展示当前版本的采集范围、最近同步状态和明确限制；提供可复现的本机启动与停止说明及无敏感演示数据。
- [ ] 保留每张前序任务已有的业务验收，本任务只负责跨功能组合及运行环境验证，不能把基础隔离和测试首次推迟到最后。
