# 07 — 标注结果并关联后续纠正

**What to build:** 用户对一次回答标记满意度和原因，并把后来补充的要求关联到原提示或输出，保存可反复查看的复盘证据。

**Blocked by:** 01 — 读取一段真实会话并在本机查看、导出

**Status:** ready-for-agent

- [ ] 可将结果标为满意、需要修改或不可用，并添加/编辑原因；标注可选，不阻塞普通采集或浏览。
- [ ] 可把后续提示手动关联到其修正的原提示或回答，并从关联双方跳转核对。
- [ ] 人工标注和关联单独保存，不覆盖原始对话；重启后仍存在，取消关联后原始记录保持可访问。
- [ ] 界面明确标注为人工判断，不根据纠正语句自动认定上一轮违规或提示导致失败。
- [ ] 标注对象以稳定来源身份关联，重复同步后不会错挂到文本相同的另一回合。
- [ ] 通过添加、编辑、取消关联和重启场景验收用户可见行为，处理全过程无需模型或远端服务。
