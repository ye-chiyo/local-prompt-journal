# 06 — 用中文搜索提示、回答和工具结果

**What to build:** 用户可以在指定项目或会话中搜索中文内容，并从命中结果定位对应回合和原始证据。

**Blocked by:** 02 — 查看工具参数、结果与执行状态；03 — 多项目自动归档与持续同步

**Status:** ready-for-agent

- [ ] 搜索覆盖已归档的用户提示、AI 消息和工具返回文本，而非只查标题或提示。
- [ ] 分别用只出现在三类内容中的中文词组验证命中，明确采用的中文匹配语义。
- [ ] 搜索结果可按项目/会话限制，展示来源、内容类型及片段，点击后定位时间线和原始证据。
- [ ] 标为部分的记录仍保留其完整性说明；缺失或截断文本不被宣称可以搜到。
- [ ] 索引与实际持久数据一致，重启后仍能检索；新增内容自动同步后能够被搜索，不要求手动同步。
- [ ] 通过应用搜索入口验收中文、混合中英文、无结果和跨范围查询，保持本机处理。
