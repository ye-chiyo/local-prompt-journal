# 01 — 读取一段真实会话并在本机查看、导出

**What to build:** 用户选择一段无敏感内容的真实 Codex 桌面会话后，能在本机看到已保存的提示原文和 AI 消息，并导出可核对的结构化记录。用这条最小路径确认实际数据源可用。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 探测当前桌面可用的只读历史入口并报告实际支持范围；优先验证正式接口，只有实测适用时才采用旧日志兼容入口。
- [ ] 完成一个选定会话的读取、本机持久保存、最小时间线显示和结构化导出；区分 AI 过程消息与最终回答，保留来源身份及原始证据引用。
- [ ] 对照预先定义的无敏感样本核对用户提示和 AI 消息；分页可用时验证跨页读取，摘要不冒充原文。
- [ ] 关闭并重新打开本地应用后，已导入内容仍能查看；显示数据源版本及已知缺口。
- [ ] 从已有候选中选择至多一个适配/查看能力做同样样本的复用检查，记录采用、部分复用或不采用的依据，不将候选文档声明当实测结果。
- [ ] 通过应用公开查询/导出与最小界面验收完整路径；另保留薄的真实接口契约检查，固定数据源仅用于可重复测试。
- [ ] 运行时日志数据存放在本机、与源码分离；新增日志组件不上传数据、不调用模型、不向原会话注入内容，也不恢复或执行历史任务。
- [ ] 若真实入口不可用或关键消息无法取得，明确报告证据与阻断原因，保持本任务未完成；后续依赖不能因模拟数据通过而解锁。
