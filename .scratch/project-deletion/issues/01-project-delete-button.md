# 项目归档提供删除项目入口

Status: ready-for-human

阶段：实现及独立审查通过，用户已授权审查通过后提交、合并和推送；正式 8766 更新另行处理。

## 需求

2026-10-28 用户要求“项目归档里面设置删除按钮，可以对项目进行删除”。

## 行为

项目归档每行提供“删除项目”入口，打开确认页后显示项目完整路径、当前全部已归档会话及数量。确认删除覆盖所有页面的已归档会话，并复用既有受管理删除及删除排除；不改变来源原会话、源码目录和另存的导出。共享附件继续按既有引用规则保留。

确认提交仅处理已核对的会话身份集合。若项目内新增或移除了会话，拒绝执行并要求重新核对，避免扩大未确认范围。会话正文更新不影响集合签名。结果逐会话报告删除成功、附件待清理或失败。

范围为当前已归档会话；不新增项目级永久采集排除，以后新建会话仍按原规则采集。不同来源或路径的同名项目以项目身份隔离。

## 验证

21 项项目删除、原有受管理删除、会话分页和 Web 验证通过；类型检查通过，UI 检测无发现。受控样本验证页面入口、GET 不修改数据、无效凭据与跨来源请求拒绝、确认后新增会话拦截、同名项目隔离、搜索与目录移除、删除排除和 105 个会话的整项目删除。

浏览器在源码外副本的 4422 首页核对每行入口，并打开 D:\AI\日志项目 的确认页：完整路径与 10 个会话一致；未点击最终删除。真实正式数据库未改写。
