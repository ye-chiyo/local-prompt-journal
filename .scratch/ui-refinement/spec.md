## 已确认方向

- 项目归档改为统一列表：项目名、会话数量、删除入口；完整路径按需展开。同名项目实施时须增加可读的路径区分，不能仅靠截断或悬停。

- 阅读区使用轻分隔和小面积角色颜色，减少整块消息底色与容器边框；保留原文、角色、阶段、完整时间、保存版本、附件与消息来源。

## 动效意图

- 选中会话／回合以约 120–150 毫秒的颜色变化确认位置。
- 所选正文加载完成后，以约 180 毫秒的局部透明度过渡表达替换；不制作全页入场、循环呼吸、滚动揭幕等干扰阅读的动画。
- 操作反馈保持快速；重复点击、加载失败和新旧响应竞争复用现有保护。
- 使用现有 CSS 与浏览器 API，无新增前端依赖；遵循 prefers-reduced-motion，减弱或取消非必要运动。
